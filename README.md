# 🎬 MOVEI – Movie Recommendation System

## 📌 About the Project

**MOVEI** is a web-based Movie Recommendation System designed to help users discover and explore movies easily. It provides a user-friendly interface where users can create an account, log in, browse movies, and search for their favourite movies.

The main goal of MOVEI is to make movie discovery simple, interactive, and enjoyable by providing an organized platform for exploring movies.

## ✨ Features

- **User Registration:** New users can create an account.
- **User Login:** Existing users can securely log in.
- **Home Page:** Explore the website through a clean and user-friendly interface.
- **Movie Search:** Search for movies by entering their titles.
- **Movie Browsing:** Explore available, featured, or popular movies.
- **Responsive Design:** Access the website through different screen sizes.

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Programming Language:** JavaScript
- **Styling:** HTML5, CSS3
- **Build Tool:** Vite
- **Database:** MongoDB (if integrated)

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the Repository**

```bash
git clone https://github.com/HirenGohil09/movie-recommendation-system-1.git
```

**2. Navigate to the Project Folder**

```bash
cd movie-recommendation-system-1
```

**3. Navigate to the Frontend Folder**

```bash
cd frontend
```

**4. Install Dependencies**

```bash
npm install
```

**5. Start the Development Server**

```bash
npm run dev
```

**6. Open in Browser**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
